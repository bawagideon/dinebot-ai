# DineBot AI — WhatsApp Gourmet Restaurant Concierge & Table Reservation RAG Bot

DineBot AI automates high-end dining table bookings, severe allergen dietary matrix checks, and sommelier vintage pairings over WhatsApp.

## Features
- **Allergen Matrix Screening**: Eliminates cross-contamination risks by filtering out nuts, gluten, shellfish, and dairy.
- **Sommelier Pairings**: Dynamically recommends vintage wines from cellar stocks for meat and seafood dishes.
- **1-Click Reservation Deposits**: Generates instant Paystack and Stripe checkout links to eliminate no-shows.
